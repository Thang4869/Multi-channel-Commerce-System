# API Gateway - Configuration & Routing Guide

## Tổng Quan

API Gateway là lớp trung gian xử lý tất cả yêu cầu từ các client (mobile app, web dashboard) đến các microservices backend. Gateway cung cấp:

- **Routing:** Định tuyến yêu cầu đến service thích hợp
- **Authentication:** Xác thực token trước khi forward request
- **Rate Limiting:** Ngăn chặn abuse, bảo vệ backend
- **Security Headers:** Bảo vệ chống XSS, Clickjacking, etc.
- **CORS:** Hỗ trợ cross-origin requests
- **Logging:** Ghi log chi tiết cho monitoring và debugging
- **Load Balancing:** Phân tải trên multiple instances (khi scale)

## Cấu Trúc Routing

### 1. Authentication Service (`/api/auth`)

**Mục đích:** Xác thực người dùng, cấp token JWT

| Method | Endpoint | Yêu cầu Auth | Mô tả |
|--------|----------|-------------|-------|
| POST | `/api/auth/login` | ❌ | Đăng nhập |
| POST | `/api/auth/register` | ❌ | Đăng ký |
| POST | `/api/auth/refresh` | ❌ | Làm mới token |
| GET | `/api/auth/profile` | ✅ | Lấy thông tin user |

**Rate Limit:** 5 req/s per IP

**Ví dụ:**
```bash
# Đăng nhập
curl -X POST http://localhost/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "email": "user@example.com",
    "password": "password123"
  }'

# Response: { access_token, refresh_token }
```

### 2. Order Service (`/api/orders`)

**Mục đích:** Quản lý đơn hàng

| Method | Endpoint | Yêu cầu Auth | Mô tả |
|--------|----------|-------------|-------|
| POST | `/api/orders` | ✅ | Tạo đơn hàng |
| GET | `/api/orders` | ✅ | Danh sách đơn hàng |
| GET | `/api/orders/{id}` | ✅ | Chi tiết đơn hàng |
| PUT | `/api/orders/{id}` | ✅ | Cập nhật đơn hàng |
| DELETE | `/api/orders/{id}` | ✅ | Xóa đơn hàng |

**Rate Limit:** 10 req/s per IP

**Timeout:** 10s

### 3. Product Service (`/api/products`, `/api/categories`, `/api/brands`)

**Mục đích:** Quản lý sản phẩm, danh mục, thương hiệu

| Method | Endpoint | Yêu cầu Auth | Mô tả |
|--------|----------|-------------|-------|
| GET | `/api/products` | ❌ | Danh sách sản phẩm |
| GET | `/api/products/{id}` | ❌ | Chi tiết sản phẩm |

| GET | `/api/categories` | ❌ | Danh sách danh mục |
| GET | `/api/brands` | ❌ | Danh sách thương hiệu |

**Rate Limit:** 10 req/s per IP

**Lưu ý:** GET requests không yêu cầu auth để cho phép public access

### 4. Inventory Service (`/api/inventory`)

**Mục đích:** Quản lý kho, lock/release stock

| Method | Endpoint | Yêu cầu Auth | Mô tả |
|--------|----------|-------------|-------|

| GET | `/api/inventory/stores` | ✅ | Danh sách store với stock |
| GET | `/api/inventory/warehouses` | ✅ | Danh sách warehouse |

**Rate Limit:** 10 req/s per IP (lock/release: 2 req/s)

**Timeout:** 15s

### 5. Delivery Service (`/api/deliveries`)

### 6. Warehouse Service (`/api/warehouses`)

**Mục đích:** Quản lý kho, phân phối

## Headers & Authentication

### Bắt Buộc Headers

```http
Authorization: Bearer <JWT_TOKEN>
Content-Type: application/json
X-Request-ID: <unique-request-id>  (optional, auto-generated by gateway)
```

### Response Headers

```http
X-Request-ID: <request-id>
Access-Control-Allow-Origin: *
Access-Control-Allow-Methods: GET, POST, PUT, DELETE, PATCH, OPTIONS
```

## Security Features

### 1. Rate Limiting

- **Standard APIs:** 10 req/s per IP
- **Auth APIs:** 5 req/s per IP
- **Heavy Operations:** 2 req/s per IP (lock/release, distribution)
- **Burst:** 20 requests allowed (queue buffer)

### 2. Authentication Check

- Public endpoints: `/api/auth/login`, `/api/auth/register`, `/api/auth/refresh`, `/api/products/*`, `/api/categories/*`, `/api/brands/*`
- Protected endpoints: Require valid JWT token in `Authorization` header
- Invalid/missing token → HTTP 401

### 3. Security Headers

```
X-Frame-Options: SAMEORIGIN              # Prevent clickjacking
X-Content-Type-Options: nosniff           # Prevent MIME sniffing
X-XSS-Protection: 1; mode=block           # XSS protection
Referrer-Policy: strict-origin-when-cross-origin
Permissions-Policy: geolocation=(), microphone=(), camera=()
```

### 4. CORS Configuration

- **Allowed Origins:** All (configurable via environment)
- **Allowed Methods:** GET, POST, PUT, DELETE, PATCH, OPTIONS
- **Allowed Headers:** All standard headers + Authorization
- **Credentials:** Allowed
- **Max Age:** 86400s (24 hours)

## Logging

Gateway ghi log chi tiết cho mỗi service:

- `/var/log/nginx/auth_service.log` - Auth requests
- `/var/log/nginx/order_service.log` - Order requests
- `/var/log/nginx/product_service.log` - Product requests
- `/var/log/nginx/inventory_service.log` - Inventory requests
- `/var/log/nginx/delivery_service.log` - Delivery requests
- `/var/log/nginx/warehouse_service.log` - Warehouse requests
- `/var/log/nginx/notification_service.log` - Notification requests
- `/var/log/nginx/access.log` - Tất cả requests

**Log Format:**
```
<IP> - <User> [<Time>] "<Method> <Path>" <Status> <BytesSent> "<Referer>" "<UserAgent>" "<X-Forwarded-For>"
```

## Performance Tuning

### Keepalive Connections
- Mỗi upstream có 32 keepalive connections
- Giảm latency cho requests liên tiếp

### Timeouts
- Connect timeout: 5s
- Send timeout: 10-15s (tuỳ service)
- Read timeout: 10-15s (tuỳ service)

### Compression
- gzip enabled cho các loại content-type phổ biến
- Compression level: 6 (balanced)

### Buffer
- client_max_body_size: 100MB
- Hỗ trợ upload file lớn

## Development & Testing

### Local Testing

```bash
# Login
TOKEN=$(curl -s -X POST http://localhost/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email": "test@test.com", "password": "pass"}' | jq -r '.access_token')

# Create order with token
curl -X POST http://localhost/api/orders \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "items": [{"product_id": 1, "quantity": 2}],
    "delivery_address": "123 Main St"
  }'
```

### Load Testing

```bash
# Simple rate limit test
ab -n 100 -c 10 http://localhost/api/products

# With auth header
ab -n 100 -c 10 -H "Authorization: Bearer $TOKEN" http://localhost/api/orders
```

## Troubleshooting

| Problem | Giải pháp |
|---------|----------|
| 401 Unauthorized | Kiểm tra token trong Authorization header |
| 429 Too Many Requests | Giảm request rate hoặc chờ rate limit reset |
| 504 Gateway Timeout | Kiểm tra service backend có chạy không |
| CORS Error | Kiểm tra preflight OPTIONS request được process |

## Thay Đổi & Maintenance

### Thêm Route Mới

1. Thêm upstream definition tại đầu file `api-gateway.conf`
2. Thêm location block cho route
3. Cấu hình rate limit, auth requirement
4. Reload nginx: `docker-compose restart nginx`

### Update Security Headers

Edit `api-gateway.conf` và thay đổi `add_header` directives

### Change Rate Limits

Sửa `limit_req_zone` definitions tại đầu file
